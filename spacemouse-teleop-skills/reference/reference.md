# LeRobot 0.6.0 SpaceMouseテレオペレータープラグイン実装知見

SpaceMouse Compact + SO-101 フォロワー + Jetson での実機構築(2026-07-31)で得た知見。
実装の実例: `lerobot_teleoperator_spacemouse`(evdev、pytest 22件、実機検証済み)。
プラグイン規約・座標系・キャリブレーション・サーボゲイン等の共通知見は
`../../joystick-teleop-skills/reference/reference.md` を参照(重複記載しない)。

---

## 1. リリース検出 — 本デバイス最大の罠

- SpaceMouseはhid-generic経由で **EV_REL(REL_X..REL_RZ)に「現在の変位」**(±350)を
  載せて、操作中約60Hz(実測: 毎秒最大22050アクティビティ=350×63イベント)でストリームする。
- **カーネルのinput層は値0の相対イベントを破棄する**。そのため手を離しても
  「0」は絶対に届かず、イベントが止まるだけ。実機キャプチャでは最終値 `REL_RZ: 346` が
  残留し、ゼロイベント数は全軸0だった。
- 素朴な「最終値キャッシュ」実装は**リリース後も最終変位で積分し続ける=暴走**。
- 対策: **軸ごとのホールドタイムアウト**。各軸の値に単調時計のタイムスタンプを付け、
  `hold_timeout`(既定0.1秒)以内に新着イベントが無ければ0を返す。
  - 操作中は60Hzで更新されるため誤失効しない(イベント間隔≈16ms << 100ms)。
  - 実機検証: 強くひねった状態から手を離し、最終2秒間の目標値ドリフト**全関節0.0°**。
  - タイムアウトを大きくしすぎない(0.2秒超でリリース応答が鈍る=危険側。設定上限0.3秒)。
- **タイムスタンプはカーネル時刻を使う**: ドレイン時刻でスタンプすると、制御ループが
  停滞した際にバッファ内の古いイベント(最終変位を含む)が「新鮮」として付け直され、
  再開後に最大 `(MAX_DT + hold_timeout) × 速度` のファントム動作が出る。
  `EVIOCSCLOCKID` ioctl(`_IOW('E',0xa0,int)` = 0x400445A0)で CLOCK_MONOTONIC を設定し、
  `event.timestamp()` を `time.monotonic()` と直接比較する(旧カーネルはフォールバック)。

## 2. デバイス特性(SpaceMouse Compact実測)

- フルスケール **±350**(回転軸はきっちり±350、並進はストローク次第で±300前後)。
- **クロストークが大きい**: 水平スライドにチルト成分が強く混入する(スライドのつもりが
  RX/RYが優勢になることも)。デッドゾーンはゲームパッドの0.15より意味が違い、
  変位比0.1〜0.15を推奨。ユーザーには「ゆっくり操作」を案内。
- 静止時も小さな残留値(7〜21/350 ≈ 2〜6%)が出ることがある → デッドゾーン0.1で吸収。
- ボタンは2個のみ(BTN_0/BTN_1)。グリッパ開/閉に使うと、エピソードイベント用の
  ボタンは残らない — `get_teleop_events` は全False固定にし、`lerobot-record` の
  キーボード操作(→/←/ESC)で代替する設計が妥当。
- **SYN_DROPPED(カーネルバッファ溢れ)でボタンのリリースを取りこぼす**と、グリッパが
  クランプ端まで動き続ける。SYN_DROPPED受信時はボタン状態を `active_keys()` で再同期し、
  軸キャッシュはクリアする(変位中なら約16msで再ストリームされる)。
- LED(EV_LED)を1個持つが未使用。

## 3. 制御設計

- 6チャンネル(slide_x/slide_y/push/tilt_fwd/tilt_side/twist)→ 関節の速度積分。
  ツイスト=旋回(pan)、押し込み=肩(lift)、前後スライド=肘、が直感的だった。
- **押し下げは正値**で届くため、lift の速度符号をデフォルトで負にして
  「押し下げ=アーム下降」に揃える(`joint_speeds` の負値で任意軸を反転できる設計)。
- slide_x(左右スライド)は5関節+グリッパでは余るため予備。将来 speed_scale の
  動的調整等に使える。
- dt上限・毎callクランプ・キャリブレーション由来リミット・robot_gains は
  ジョイスティック/MIDI編と同一パターン。

## 4. 権限まわり(Jetson)

- /dev/input のアクセスは input グループ or udevルール。**プロセス再起動でグループが
  外れて突然読めなくなる**ことがある(evdev.list_devices() が空を返す)。
  udevルール(vendor 256f、`TAG+="uaccess"`)を入れておくのが確実:
  `KERNEL=="event*", ATTRS{idVendor}=="256f", MODE="0660", GROUP="input", TAG+="uaccess"`
- 即時解放は `setfacl -m u:$USER:rw /dev/input/eventX`(ノード再生成で消える)。

## 5. 実機検証の記録(2026-07-31)

- SpaceMouse Compact(256f:c635)をUSB idで自動識別、event6接続。
- 90秒ドライラン: 6制御経路すべて応答(pan ±80°、lift -180°、elbow +96°、
  wrist_roll、グリッパ0↔100フル)。
- **リリーステスト合格**: 強変位から手を離した後の最終2秒ドリフト全関節0.0°。
- 実ロボット(SO-101)接続での動作もユーザー確認済み。
